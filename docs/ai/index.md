# Recursos de IA

Esta documentación está hecha para que la lea una persona o un agente. Todo el
contenido existe también como Markdown plano, en archivos pensados para
caber en un contexto.

## Páginas

- [Instrucciones para agentes](./agent-instructions): el contrato de trabajo.
- [Estrategia de contexto](./context-strategy): qué cargar según la tarea.
- [Prompt maestro](./master-prompt): un prompt listo para pegar.
